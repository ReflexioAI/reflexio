# Reflexio

Local-first memory backend for coding agents: it extracts durable knowledge
from agent sessions, stores it, and retrieves it back into future turns.

## Language

### Evidence

**Interaction**:
One stored turn (User or Assistant) of a real agent session — the raw evidence
row that evaluation is computed from.
_Avoid_: message, log entry, event

**Request**:
One publish batch from a client, carrying the `session_id` and the
`evaluation_only` fence. Interactions belong to exactly one request.
_Avoid_: call, submission

**Session**:
A single client conversation, identified by the host agent's session id
(e.g. Claude Code's). The unit that links interactions back to what the user
actually experienced.
_Avoid_: conversation, thread

### Knowledge

**Playbook**:
A learned, retrievable rule. `user_playbook` is scoped to one user/project;
`agent_playbook` is shared across them.
_Avoid_: lesson, skill, rule (client-facing aliases; not used in this codebase)

**Profile**:
A retrievable fact about who the user is or what they prefer, as opposed to a
procedure.
_Avoid_: preference (client-facing alias)

### Retrieval

**Retrieved learning**:
One learning (profile or playbook) that was retrieved and injected into a live
turn, declared by the client on the published interaction
(`Interaction.retrieved_learnings`) — everything shown, whether or not it
helped.
_Avoid_: recall, injection (client-side words for the same event)

**Citation**:
The assistant's acknowledgment that a retrieved item materially changed its
response, recorded on the Assistant interaction.
_Avoid_: reference, attribution

### Data lifecycle

**Retention**:
Row-count-based trimming of capped storage tables (delete oldest ~20% past the
limit). Mechanical space management, never a judgment about the data.
_Avoid_: cleanup, expiry

**Archive**:
The append-only JSONL record of rows removed by retention (see ADR-0001).
Live table ∪ archive = full history while enabled.
_Avoid_: export, backup, snapshot

**Purge**:
Governance-driven erasure of a subject's data (right-to-erasure). Entirely
separate path from retention; purge creates no archive records and does not
erase records that retention archived earlier.
_Avoid_: delete (too generic), retention (different mechanism)

**Evaluation-only**:
The fence marking traffic generated by evaluation tooling (`requests.evaluation_only`)
so evals never teach the product or grade their own output.
_Avoid_: test traffic, synthetic
