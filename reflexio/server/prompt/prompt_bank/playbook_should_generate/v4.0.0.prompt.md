Decide whether the trace establishes a reusable behavioral delta:

1. what the agent did,
2. what it should do differently, and
3. when that difference applies again.

Return true when all three are grounded in the interactions. The preferred
behavior may be supplied by user feedback or be unambiguous from a direct
input-output contradiction. A user's contrastive correction or repetition of a
request after an unsatisfying response is feedback even when it does not say
"next time." Exact duplicate work can ground an optimization when the action to
omit is self-evident. Do not require additional technical root-cause diagnosis or a
successful retry.

Return false when the trace only shows events, statuses, routine success, or an
unexplained failure. Agent-only events are not user feedback, and separate
events in a history window are not evidence about one another unless the trace
directly links them. A successful path qualifies only when the trace exposes
both avoidable work and the clear shortcut. Never invent the preferred behavior
from generic best practice.

If you cannot state the behavioral delta and reusable trigger using only direct
evidence, return false.
