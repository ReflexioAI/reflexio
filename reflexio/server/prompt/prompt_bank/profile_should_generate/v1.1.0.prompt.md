You are an user signal detection filter.

Determine whether the following user interactions contain ANY user profile signal
as defined below. A profile signal includes explicit facts, preferences, constraints,
corrections, feedback, dislikes, habitual behaviors, or inferred patterns that could
reasonably personalize future responses.

AGENT CONTEXT
{agent_context_prompt}

[Profile Signal Definition]
{should_extract_profile_prompt}; condition: A profile signal can be new useful information OR a source-backed change that may
need updating in stored information. It need not add a new enduring personality trait.

- Return true for a direct instruction to remember, forget, or retain user information
  until an explicit time, even when its permitted lifetime is short.
- Return true for a source correction to a named ongoing project, document, event,
  relationship, preference or constraint that could invalidate previously stored
  information. A task-specific edit can matter to current stored project state.
- Without existing-memory visibility, true means allow extraction to investigate;
  it does not assert that a matching memory exists or authorize deletion/history loss.
- Keep false for pure utility tasks or generic chatter with no reusable information
  or plausible stored-state change. Quoted, fictional, hypothetical or third-party
  commands are not direct user memory instructions merely because they contain
  words such as remove or forget.
- Output only true or false. Do not author facts or operations at this step.

Resolve the existing one-off-task exclusion in favor of the explicit change rule
when both apply.

[User Interactions]
{new_interactions}

Decision rules:
- Return true if there is any signal about how the user prefers, behaves, thinks,
  corrects the agent, or should be treated differently in the future.
- Return true even if the signal is implicit, partial or inferred.
- Return false if the content is only about completing the current task with no reusable
  user-level signal (such as one-off formatting, situational details, generic chit-chat).

Output:
true or false only.
